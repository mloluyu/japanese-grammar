# 练习题编写指南

> 不需要会编程：题目写在固定格式的题目文件里（照 `content/quizzes/` 下现有文件抄结构），真正决定能否过审的是下面的质量规则。

::: tip 让网页版 AI 帮你起草
把一个现有题库文件的内容复制给网页版 AI 当格式示例，说明你想考查的语法点和题型想法，让它按同样格式生成候选题。AI 生成的题目必须自己逐条核对答案与解析无误后再提交；同样，不要把受版权保护的教材、题库内容粘贴给 AI。
:::

## 1. 难度语义

难度是 1–3 的整数（数据结构见《内容数据规范》`project-docs/CONTENT_SCHEMA.md` 第 4 节），本表是唯一口径：

| 难度 | 含义 | 特征 |
|---|---|---|
| 1 | 直接识别 | 单一语法点填空，选项词性一致，读懂句子结构即可作答 |
| 2 | 语境应用 | 必须理解句意或场景才能选出正确项 |
| 3 | 易错辨析 | 近义干扰项；解析必须说明错误选项为什么不行 |

题目通过 `grammarIds` 自动出现在对应语法条目页的「小练习」区（构建时按条目过滤），不需要在语法正文中登记题目。一道题写了多个 `grammarIds` 时，会同时出现在这些条目上——适合做成对比题。

## 2. 出题质量规则

1. **空格唯一性**：题干不能存在两个位置填同一答案都通的情况。
2. **干扰项来自真实误用**：应选取学习者常混淆的形式，而不是随机凑的词。
3. **选项同质性**：长度、词性尽量接近，避免"最长的是答案"这类长度或词性线索。
4. **答案位置有意识分布**：同一组题目中避免答案全部集中在同一选项。
5. **关联真实**：`grammarIds` 必须对应题目实际考查的语法点。

## 3. 解析要求

- `explanation` 非空是最低要求，有解释力是审核标准。
- 难度 3 的题目必须说明错误选项不成立的原因。
- 解析中涉及的语法应能通过 `grammarIds` 链接到对应条目。

## 4. 提交前自查

- [ ] 题目 ID 全局唯一。
- [ ] 答案索引指向正确的选项。
- [ ] 干扰项与正确项同质，无长度或词性线索。
- [ ] 解析能解释正确答案；难度 3 题目说明了错误项。
- [ ] `grammarIds` 与考点一致。
