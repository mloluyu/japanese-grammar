# 内容审核指南

## 1. 审核目标

审核的目标是提高准确性、可读性和可维护性，而不是要求所有条目采用完全相同的解释风格。

## 2. 审核清单

### 语言准确性
- [ ] 语法含义没有明显错误。
- [ ] 接续形式完整。
- [ ] 例句自然且确实体现目标语法。
- [ ] 中文释义与日语原句匹配。
- [ ] 语域、语境与常见限制有适当说明。
- [ ] 相似表达的区别不是过度简化的绝对规则。

### 数据质量
- [ ] 必填 Frontmatter 字段完整。
- [ ] ID 唯一且稳定。
- [ ] 分类与标签遵循现有约定。
- [ ] 关联条目存在；「相似表达」未手写重复链接。
- [ ] 题目答案索引正确，解析有解释力。
- [ ] 音频路径正确，文件确实可播放。

### 来源与版权
- [ ] 来源可追溯。
- [ ] 没有未经许可复制教材、题库或他人音频。
- [ ] 引用、署名和许可要求得到遵守。

## 3. 处理有争议的条目

1. 明确争议点是语义、接续、语域还是分类。
2. 请求提供具体语境和参考依据。
3. 若不同解释都成立，分别写明适用条件。
4. 无法确定时暂时标记待核实，不要发布未经验证的强断言。

## 4. 审核结果

- Approve：内容可合并。
- Request changes：指出必须修正的问题。
- Comment：提出非阻断建议或讨论。

自动化检查只能验证结构和部分一致性，不能替代日语内容审核。
