# 决定、努力与变化

这一组句型都围绕"对事态施加控制"，但控制的性质不同：是谁决定的、坚持多久、结果如何。它们经常出现在同一段对话里，放在一起记才不会混。

## 邀请与提议（N5）

| 句型 | 语义 | 语气 |
|---|---|---|
| 〜ませんか | 邀请："要不要…？" | 委婉，把选择权交给对方 |
| 〜ましょう | 提议："一起…吧" | 直接，带推进意向 |

被拒绝时，「〜ませんか」的否定疑问形式让双方都有台阶；对上级更稳妥的是「〜ていただけませんか」这类请求形式。详见 [〜ませんか](/grammar/masen-ka) 与 [〜ましょう](/grammar/mashou)。

## 决定 → 坚持 → 变化（N3）

| 句型 | 语义 | 决定者 / 性质 |
|---|---|---|
| 〜ことにする | 主动决定要（不）做 | 当事者自己，一次性拍板 |
| 〜ことになる | 事情被决定为… | 外部安排、协商结果 |
| 〜ようにする | 尽量做到（避免） | 自己，持续的努力或习惯 |
| 〜ようになる | 变得能（会、常）… | 无意志控制，变化的结果 |

三者构成一条链：先「ことにする」拍板，再「ようにする」天天坚持，最后「ようになる」看到变化。

- 调职、公司安排这类"由外部决定"的事基本只用「ことになる」：「来年から名古屋で働くことになりました。」
- 自己主动决定的事误用「ことになる」，会带出"不是我想的"的推脱语感。
- 「ようにしています」是习惯性的坚持；「ことにしています」是自己定下的规矩。两者都持续，但前者强调努力，后者强调规则。

## 常见混淆

- 「ことにする」vs「ことになる」：看决定者。主动拍板用前者，被安排用后者。
- 「ようにする」vs「ようになる」：看是否还在控制。坚持做是前者，已经能了/习惯了是后者。
- 「ことになっている」表示规则惯例（"这里规定不…"），与「ことになる」的"决定"义不同。
