# 自动词与他动词

日语动词按「动作是否需要作用到对象」分为两类：**自动词**（不需要带对象，变化或状态自己发生）和**他动词**（需要对象，对象用「を」标记）。这不是句型，而是读句子、查词典时都用得上的基础术语。

## 怎么区分

看动词和哪个助词搭配，是最直接的线索：

- 自动词常和「**が**」连用：ドア**が**開く。——门（自己）开了，没有人去开它。
- 他动词常和「**を**」连用：ドア**を**開ける。——有人把门打开，动作落到「ドア」上。

> ドアが　開く。／门（自己）开了。
> ドアを　開ける。／把门打开。
> 電気が　消える。／灯灭了。
> 電気を　消す。／把灯关掉。

同一个「开」的状态，自动词句呈现**变化发生了**，他动词句强调**谁对它做了什么**——这是两 类句子最本质的分工。

## 成对记忆

很多自动词与他动词成对出现，形态上有一些常见对应（如「〜く ↔ 〜ける」「〜える ↔ 〜す」），但规律不完全，建议成对记忆：

| 自动词 | 他动词 |
| --- | --- |
| 開く（あく） | 開ける（あける） |
| 消える（きえる） | 消す（けす） |
| 割れる（われる） | 割る（わる） |

也有大量不成对的动词：ある、いる、行く、咲く只有自动词；買う、食べる、読む只有他动词。

## 注意

- 不能只看助词下结论：「公園**を**散歩する」里的「を」表示移动经过的场所，不是宾语，散歩する仍是自动词性用法。
- 词典里标注「自」即自动词、「他」即他动词；查词典确认比自己猜可靠。

## 参照

- 与「〜ようにする／〜ことになる」搭配时，自动词和他动词的选择会改变句子含义（「ドアが開くようにした」对「ドアを開けるようにした」），可对照[〜ようにする](/grammar/you-ni-suru)、[〜ことになる](/grammar/koto-ni-naru)体会。
