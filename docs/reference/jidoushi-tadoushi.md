# 自动词与他动词

日语的动词按是否需要宾语分成两大类。这一对概念是理解「〜が上がる／〜を上げる」这类成对句型的钥匙，也是本站[自动词与他动词条目](/grammar/jidoushi-tadoushi)的语法基础。

## 两个定义

**自动词（自動詞）**描述不涉及他物的变化或状态，主体直接用「が」标记：

> ドアが　**開く**。　（门开了。）

**他动词（他動詞）**描述某人作用于他物，作用对象用「を」标记：

> （私が）ドアを　**開ける**。　（我开门。）

同一扇门，「開く」关注门自身的状态变化，「開ける」关注人施加的动作。谁导致、谁承受，决定了选哪个词。

## 成对与不成对

许多自动词／他动词像「開く／開ける」一样成对出现，但**并非所有动词都有另一半**：

- 有的只有自动词：ある、いる、行く、来る、咲く
- 有的只有他动词：買う、食べる、読む、書く
- 有的形式相同、靠助词区分：**開く**（あく，自动词）与**開く**（ひらく，自动词／他动词两用）是两个词
- 「を」不一定是他动词的标志：「公園**を**走る」的「を」表示经过的场所，动词仍是自动词

## 学习提示

1. 遇到成对动词，先问「这句话想描述**状态变化**还是**施加动作**」。
2. 自动词句的重点在**结果呈现**（门处于开着的状态这个事实），他动词句的重点在**责任归属**（谁干的）。
3. 説明文、新闻报道多用自动词（客观呈现），指令、流程说明多用他动词。
