# 〜ことにする

## 核心含义
说话人（或当事者）就某事主动做出决定：要…、不…。决定者明确是自己，句子基本都能改写成「〜することを決めた」。

## 接续
- 动词辞书形／ない形＋ことにする（行くことにする、行かないことにする）

## 相似表达
「〜ことになる」是被决定、协商的结果，决定者不在句中凸显；「〜ようにする」是"尽量做到"的持续努力，不含一次性拍板的语义。单纯陈述决定的事实也可以直接说「〜と決めた」。

## 使用注意
- 「〜ことにしている」表示自己给自己定下的规矩（已经习惯化），与一次性的「ことにした／する」分开使用。
- 否定决定用「〜ないことにする」。
- 决定后向别人说明缘由时，常与「〜から」「〜ので」等理由表达连用。

## 参考与补充
