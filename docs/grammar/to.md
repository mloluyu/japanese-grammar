# 〜と（条件）

## 核心含义
表示恒常条件：只要前项成立，后项就必然、规律性地发生——自然规律、习惯、机器或操作说明。另一种用法是"一起发现"：做了某个动作，就发现了出乎意料的事态。

## 接续
- 动词辞书形／ない形＋と（行くと、行かないと）
- い形容词辞书形＋と（安いと）
- な形容词词干／名词＋だと（静かだと、休みだと）

## 例句
例句由结构化例句数据渲染，不在正文中手写。配套例句：`docs/grammar/to.json`。

## 相似表达
「と」的后项是"必然如此"的事态，不受说话人意志左右，因此不能接命令、劝诱或意愿表达——这是它与「たら」「ば」最大的区别。「開けると、猫がいた」这种一次性的"发现"是「と」独有的用法。「ば」「たら」的说明见各自条目。

## 使用注意
- 后项不能是命令、劝诱、意愿（×押すと、電気をつけてください）。
- 「〜と」另有引用助词的用法（「行く」と言った），注意区分。
- 恒常用法要求前后项是可反复对应的规律关系，一次性的假定用「たら」更自然。
