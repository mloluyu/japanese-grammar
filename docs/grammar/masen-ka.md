# 〜ませんか

## 核心含义
用否定疑问的形式邀请或提议对方（一起）做某事。把"做不做"的选择权交给对方，语气委婉，即使被拒绝也不至于尴尬。

## 接续
- 动词ます形（去ます）＋ませんか
  - 食べます → 食べませんか
  - 行きます → 行きませんか

## 相似表达
「〜ましょう」是直接的提议——"一起…吧"，说话人已带有推进的意向；「〜ませんか」则先征求对方意愿，更留有余地。被邀请而想拒绝时，通常不直接说「行きません」，而是用「すみません、ちょっと…」这类含糊的说法缓冲。

## 使用注意
- 不是对习惯或状态的否定提问。「毎日コーヒーを飲みますか。（→ 飲みません）」问的是事实；「飲みませんか」才是邀请。
- 对上级使用虽然礼貌，但请求对方"为自己做事"时，「〜ていただけませんか」更稳妥。
