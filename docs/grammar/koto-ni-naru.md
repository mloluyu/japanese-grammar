# 〜ことになる

## 核心含义
表示某事被决定为…：决定可能来自协商、安排或外部情况，说话人不强调"是我拍板的"，整体口吻客观，像在陈述一个已经成形的结果。

## 接续
- 动词辞书形／ない形＋ことになる（行くことになる、行かないことになる）

## 相似表达
「〜ことにする」是当事者自己主动拍板；「〜ことになる」则是被安排、协商出来的结果——调职、歇业这类"由外部决定"的事基本只用后者。「〜ようになる」与决定无关，表示能力或习惯的变化。

## 使用注意
- 自己主动决定的事却用「ことになる」，会带出"不是我想的，是形势如此"的推脱语感（有时被刻意用来委婉交代）。
- 「〜ことになっている」表示规则、惯例（这里规定不…），语义不同，注意区分。
