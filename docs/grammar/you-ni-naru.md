# 〜ようになる

## 核心含义
表示能力或习惯性状态发生了变化：变得能…、变得（开始）…、变得不再…。变化是自然形成或长期积累的结果，句子不强调"是谁在控制"。

## 接续
- 动词可能形＋ようになる（泳げるようになる：变得会…了）
- 动词辞书形＋ようになる（食べるようになる：开始吃…了，习惯的变化）
- 动词ない形＋ようになる（食べないようになる：变得不…了）

## 相似表达
「〜ようにする」是人为地努力维持或达成某事；「〜ようになる」是努力之后自然出现的变化结果。「〜ことにする」则是拍板决定。三者构成"决定 → 坚持 → 变化"的对照链。

## 使用注意
- 可能形＋ようになる（泳げるようになる）是核心用法，表示从不会到会。
- ない形＋ようになる（食べないようになった）表示改掉某个习惯；注意与「食べられないようになった」（变得吃不了）意义不同。
- 前项是瞬间动词时，表示该事态开始反复出现（新しい店を利用するようになった）。
