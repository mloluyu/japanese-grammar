# 〜なら

## 核心含义
承接对方话语中刚出现的信息，把它当作前提或话题，给出判断、建议或补充信息："要说…的话""如果是…的话"。前项通常来自对话，后项常带说话人的评价。

## 接续
- 动词辞书形／た形＋なら（行くなら、行ったなら）
- い形容词辞书形＋なら（安いなら）
- な形容词词干／名词＋なら（静かなら、学生なら——不需要再加 だ）

## 相似表达
「なら」不表达恒常规律，也不单纯表示时间先后（那用「たら」）；它的特长是"就着对方的话题往下说"。后项可以是建议、意愿、命令——这是它与「と」「ば」的重要区别。「A なら B」里 B 常是对 A 的评价或推荐，而不单纯是结果。

## 使用注意
- 名词・な形容词直接加「なら」：学生なら○、学生だなら×。
- 「行くなら」与「行ったら」都能译成"如果去"，但「なら」带有"以你要去为前提"的话题性。
- 前项最好是已经进入对话的信息；凭空冒出的假定用「たら」「ば」更自然。

## 参考与补充
例句均为本项目原创。「なら」的话题性与"取り立て"性质，是它与一般假定条件分工的核心。
