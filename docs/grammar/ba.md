# 〜ば

## 核心含义
假定条件："只要以…为条件，就会…"。也可以表示随一般条件反复出现的结果，以及「〜ば〜ほど」（越…越…）的固定搭配。前项侧重条件本身，整体语感比「たら」更书面、更一般化。

## 接续
- 动词ば形：行く → 行けば、する → すれば、来る → 来れば
- い形容词去い＋ければ（安い → 安ければ）
- な形容词／名词＋であれば（口语的条件义常用「なら」）

## 相似表达
与「たら」相比，ば 前后项的时间先后感较弱，更适合一般性的假定或恒常关系；前项是状态性谓语（可能形、ある・いる 等）时习惯用 ば（時間があれば、行きます）。「と」的后项是必然规律，不能接意志表达；「なら」承接话题给建议。

## 使用注意
- 前项为动作动词、后项是意志・劝诱时不宜用 ば（×行けば、教えてください）；这种"一次性假定＋请求"用「たら」：行ったら、教えてください。
- 前项是状态时，后项可以出现意志表达：安ければ、買ってください。
- 「〜ば〜ほど」表示"越…越…"，是固定搭配：食べれば食べるほどおいしくなる。

## 参考与补充
例句均为本项目原创。ば句的后项制约是条件表达教学中的经典论点，可与「たら」「と」条目对照使用。
