# 〜ましょう

## 核心含义
礼貌地提议对方与自己一起做某事（"…吧"）；也可以表示说话人自己的意志（"我来…吧"）。

## 接续
- 动词ます形（去ます）＋ましょう
  - 始めます → 始めましょう
  - します → しましょう

## 相似表达
「〜ませんか」先征求对方意愿，更委婉、留有余地；「〜ましょう」语气更直接，隐含"就这么定了"的推进感。对上级或长辈单用「ましょう」提议一起做事有时显得轻率，此时「〜ませんか」更稳妥。「〜ましょうか」则带出"要不要我（们）来…"的服务、协助语气。

## 使用注意
- 表示意志（"我来做吧"）时，动作主体是说话人自己；邀请用法里动作由双方共同完成。
- 正式场合或书面通知里，「〜いたします」（谦让语）会取代「します」。
