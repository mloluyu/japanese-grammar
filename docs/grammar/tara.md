# 〜たら

## 核心含义
条件表达里最通用的一种：既可表示假定条件（"如果…的话"），也可表示确定条件（"…之后，就…"）。前后项之间有明显的"前一件事触发后一件事"的时间感，多用于一次性的、具体的事态。

## 接续
- 动词た形＋ら（行く → 行ったら）
- い形容词去い＋かったら（安い → 安かったら）
- な形容词词干／名词＋だったら（静か → 静かだったら）

## 相似表达
「〜と」表达不受意志左右的恒常关系（自然规律、习惯、操作说明）；「〜ば」偏重"以…为条件"的一般性假定，书面色彩稍强；「〜なら」承接对方刚提到的话题，在此基础上给建议或判断。后项可以出现意志和请求，是「たら」比「と」自由的地方。

## 使用注意
- 名词・な形容词要用「だったら」，不能直接接「たら」。
- 「大学に行ったら」既可理解为"去了大学之后"，也可理解为"如果去大学"，取哪种意思由语境决定。
- 表达恒常规律（"一到春天就开花"）时用「と」更自然；「たら」偏向一次性的、新出现的事态。

## 参考与补充
例句均为本项目原创。「たら」的"发现"用法（行ってみたら、人がいた）可对照「〜と」条目的"发现"用法比较。
