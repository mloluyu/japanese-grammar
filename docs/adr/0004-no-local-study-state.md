# ADR-0004：不实现本地学习记录

- 状态：Accepted
- 日期：2026-10-09

## 背景

初始设计包含收藏、错题记录与偏好等 localStorage 学习数据（见 ADR-0003）。维护者评估后认为：站点定位是"查阅 + 练习"，跨会话保存个人学习数据带来的数据模型、版本迁移、异常处理、隐私说明与测试成本，相对其实际价值过高，该功能没有意义。

## 备选方案

- 保留 localStorage 学习状态：支持收藏与错题回顾，但增加持久化与迁移成本。
- 服务端账户与同步：明确属于 MVP 非目标。
- 不保存任何学习数据：练习反馈即时展示，交互状态仅存在于当前页面会话。

## 决策

不实现任何本地学习数据持久化。删除收藏、错题回顾与偏好记忆功能；练习状态仅在当前页面会话内有效。本决策取代 ADR-0003 中"localStorage 学习状态"的部分，ADR-0003 的静态托管决策继续有效。

## 后果

- 删除 FR-06（本地学习记录）、本地状态模型与相关验收项，产品面更聚焦。
- 隐私声明更简单：站点不收集、不持久化任何个人学习数据。
- 练习的反馈与解析仍然即时可用；假名开关在当前页面会话内有效。
- 若未来群友明确提出跨会话学习记录需求，应重新评估并新增 ADR。

## 复审条件

出现真实的跨会话学习记录需求（如错题回顾被多次提出）时。
