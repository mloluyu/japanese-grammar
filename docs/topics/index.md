# 专题

专题页把若干条语法放在一起做系统对比，适合按主题集中理解；每条的完整说明、接续与例句仍以各语法页为准。

## 现有专题

- [条件表达：と・ば・たら・なら](/topics/conditionals) —— 四种条件形式的分工与后项制约。
- [决定、努力与变化](/topics/decision-and-intention) —— 决定句型与意志、坚持、变化表达的对照。

## 新增专题

专题与分类不同：分类是条目的单一归属（Frontmatter 的 `category`），专题是跨条目的策展页面。想新增专题时，先在 [GitHub 上开 issue](https://github.com/mloluyu/japanese-grammar) 讨论范围，再按现有专题的结构撰写。
