# 条件表达：と・ば・たら・なら

日语的条件表达由四个句型分工完成。它们常被译成同一个"如果"，但侧重不同，后项能接什么也受限。先看总表，再看细节。

## 总览对比

| 句型 | 侧重点 | 后项能否接意志・劝诱 | 典型场景 |
|---|---|---|---|
| 〜と | 恒常规律、自然结果、"一起发现" | 不能 | 机器操作、自然规律 |
| 〜ば | 以…为条件的一般假定，偏书面 | 动作性前项不能，状态性前项可以 | 一般假定、能力条件 |
| 〜たら | 最通用；一次性事件、时间先后 | 可以 | 日常假定、"…之后" |
| 〜なら | 承接话题，给评价或建议 | 可以 | 就着对方的话往下说 |

## 各自的分工

**〜と** 描述"只要 A 就必然 B"的稳定关系：自然规律、习惯、操作说明。「春になると、桜が咲きます。」后项是说话人控制不了的事态，所以命令、劝诱、意愿都不能接。它还独有一种"发现"用法：做了某动作，眼前出现了意外状况（「開けると、猫がいた」）。

**〜ば** 把前项当作条件提出，语感偏书面、偏一般化。前项是状态性谓语（可能形、ある・いる 等）时，后项可以自由出现意志表达：「時間があれば、行きます」；前项是动作动词时则不行，这类"假定＋请求"交给 〜たら。

**〜たら** 是日常对话的默认选项：一次性的、具体的、有时间先后感的事态都用它。「家に帰ったら、すぐ電話してください。」既可以是"如果到家"也可以是"到家之后"，由语境决定。

**〜なら** 不表示规律也不表示先后，它的前项来自对话中刚出现的信息：「日本語を勉強しているなら、この辞書がおすすめです。」后项常是对前项的评价、建议或补充，这是它独有的功能。

## 如何选择

1. 说自然规律、操作步骤 → 〜と
2. 一般性的假定条件，尤其前项是状态 → 〜ば
3. 日常假定或"…之后就…" → 〜たら
4. 对方刚提到某事，你要给建议或评价 → 〜なら
