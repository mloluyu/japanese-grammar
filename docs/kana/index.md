# 五十音图

五十音是日语假名的基础排列。这里是速查表：横为行、竖为段，每个假名标注了平假名、片假名和罗马字。**点击任意假名格可以听发音**。假名还不熟时，先记读法、再认字形即可。

## 清音（46 个）

<KanaChart part="seion" />

清音是全部假名的骨架。拨音 **ん**（n）不属于任何行，单独记一个。

> 「を」在现代日语里只当助词用，读作 o。や行的い、え，わ行的い、う、え在历史上有对应假名（ゐ、ゑ），现代日语已不使用。

## 两个书写符号

- **长音**：把元音拖长一拍。平假名直接重复元音假名（「おかあさん」的「あ」），片假名用「ー」（「コーヒー」）。
- **促音**：小写「っ」，表示停顿一拍，不单独发音（「がっこう」学校）。长音和促音都不单独发音，因此表里没有它们的格子。
