# 测试策略与验收用例

## 1. 测试层次

### 数据校验测试
- 缺少必填 Frontmatter 时失败。
- JLPT 值不属于 N5–N1 时失败。
- `tags` 中出现 `N5`–`N1` 等级标签时失败（等级只由 `jlpt` 字段维护）。
- 重复语法 ID 或题目 ID 时失败。
- 关联语法 ID 不存在时失败。
- 分类未在注册表 `docs/.vitepress/categories.json` 中定义时失败。
- 例句 JSON 的 `grammarId` 与文件名或条目 ID 不一致、例句 ID 重复、`furigana` 文本未在句中出现时失败。
- 答案索引越界、选项不足或解析为空时失败。
- 题目 `grammarIds` 引用不存在的条目或难度越界时失败。

### 构建测试
- `npm run docs:build` 成功。
- 所有页面在构建后能正常访问。
- 按站点 base 配置核对资源 URL（当前为根路径 `/`）。
- Markdown 内部链接有效（如已配置链接检查）。

### 组件测试
- 筛选条件可叠加与重置。
- 搜索或筛选无结果时有空状态。
- 单选题选择后显示反馈与解析。
- 重新开始练习会重置当前题状态。
- 没有音频的例句不会显示损坏的播放器。
- 假名开关只影响标注显示，不破坏句子布局。

### 手工验收
- 桌面与窄屏布局可用。
- 键盘可以操作搜索、筛选和练习控件。
- 搜索「ことになる」可命中对应条目；日语正文片段的搜索行为符合验证结论。
- 日语、假名和中文显示正常。
- 日语内容由 `lang="ja"` 标记（至少例句组件），站点根 `lang` 为 `zh-CN`。
- 无音频、慢网络和空数据情况下页面仍可阅读。
- 静态托管生产地址无路径错误。

## 2. 发布前验收清单

- [ ] 所有自动检查通过。
- [ ] PR 已由维护者审核。
- [ ] 新增内容有合理来源与版权依据。
- [ ] 语法 ID 唯一且关联有效。
- [ ] 音频和图片有再分发权限。
- [ ] 移动端和桌面端至少各检查一次。
- [ ] 正式部署成功且公开 URL 可访问。
- [ ] `README` 与贡献指南和当前实现一致。

## 3. 缺陷优先级

- P0：网站无法访问、内容泄露、构建/部署严重故障。
- P1：核心搜索、筛选或练习功能不可用。
- P2：单个条目、音频、链接或样式异常。
- P3：视觉微调、非关键体验改进。

优先级由维护者根据影响范围与可复现性确认。
