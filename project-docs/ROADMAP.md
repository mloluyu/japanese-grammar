## Milestone 3：检索与导航

- [x] 启用本地全文搜索并加入 CJK 二元分词（docs/.vitepress/search-tokenizer.mjs；scripts/verify-search.mjs 已证实：默认分词下句中片段查询 4/6 落空，二元分词 6/6 命中，脚本已并入 npm run check）。例句文本经 search-render.mjs 注入索引，验证语料与真实索引一致。

## Milestone 4：练习体验

- [x] 定义单选题 JSON schema（CONTENT_SCHEMA 第 4 节；validate-quiz 校验）。

## Milestone 5：例句体验

- [x] 实现假名显示切换（ExampleSentences 组件：`<ruby><rt>` 输出，一键切换显示/隐藏，状态仅存于会话内存，遵守 ADR-0004）。
- [x] 实现音频播放器与无音频状态（有 `audio` 字段时输出原生播放器并走 base 前缀；缺失时显示「暂无音频」，不渲染失效控件。真实音频文件待贡献）。

- [x] 验收：无音频、切换假名等场景下例句渲染正常（构建产物验证 ruby 结构与占位行为；浏览器端确认随正式发布进行）。

## 暂缓项目

在核心体验稳定前，不安排：
- 复杂间隔重复算法。
- AI 自动写入正式语法条目。
- 实时多人编辑。
- 大规模音频托管迁移。

## 变更规则

每次里程碑完成后更新状态；新增需求应说明用户价值、复杂度与对现有结构的影响。重大架构变化通过 ADR 记录。
