# 开发路线图

路线图按可验收的交付物划分，不以堆叠功能数量为目标。日期与工作量应在维护者确认可用时间后再补充。

## Milestone 0：仓库初始化

- [x] 选择许可证：代码 MIT，内容 CC BY-SA 4.0。
- [ ] 在 GitHub 创建 `japanese-grammar` 仓库并推送。
- [x] 初始化 VitePress、Vue 3 与 TypeScript 配置。
- [x] 添加首页、导航和基础主题。
- [x] 配置 Pages 工作流。
- [ ] 验收：空白站点可成功部署（首次 Pages 部署成功后勾选）。

## Milestone 1：内容规范

- [ ] 完成语法 Frontmatter 模板。
- [ ] 编写 5–10 条示例语法（MVP 验收前补足到不少于 10 条）。
- [ ] 建立分类 ID 与标签约定。
- [ ] 添加内容编写与审核指南。
- [ ] 验收：贡献者可根据模板新增条目。

## Milestone 2：质量门禁

- [ ] 实现语法数据校验。
- [ ] 实现题库 JSON 校验。
- [ ] 检查重复 ID 与失效关联。
- [ ] PR 自动运行校验与构建。
- [ ] 验收：故意引入错误时，CI 能失败并指出位置。

## Milestone 3：检索与导航

- [ ] 启用本地全文搜索，先用真实日语样本验证分词效果，必要时在搜索配置中加入 CJK 二元分词。
- [ ] 生成语法索引。
- [ ] 实现 JLPT、标签与分类筛选。
- [ ] 建立专题索引与相似语法链接。
- [ ] 验收：用户可以通过关键词和组合筛选找到条目。

## Milestone 4：练习体验

- [ ] 定义单选题 JSON schema。
- [ ] 实现练习组件、反馈与解析。
- [ ] 按等级/语法抽题。
- [ ] 答题反馈中的链接可跳转到对应语法页面。
- [ ] 验收：完整完成一轮练习，答题后能看到答案、解析与相关语法链接。

## Milestone 5：例句体验

- [ ] 实现假名显示切换。
- [ ] 实现音频播放器与无音频状态。
- [ ] 例句组件输出正确的 `lang` 标记。
- [ ] 验收：无音频、切换假名等场景下例句渲染正常。

## Milestone 6：群内试运行

- [ ] 邀请少量群友试用。
- [ ] 收集搜索失败案例与内容错误。
- [ ] 检查移动端使用体验。
- [ ] 调整贡献流程和审核清单。
- [ ] 验收：至少一位非开发者通过网页编辑成功提交内容。

## 暂缓项目

在核心体验稳定前，不安排：
- 复杂间隔重复算法。
- AI 自动写入正式语法条目。
- 实时多人编辑。
- 大规模音频托管迁移。

## 变更规则

每次里程碑完成后更新状态；新增需求应说明用户价值、复杂度与对现有结构的影响。重大架构变化通过 ADR 记录。
