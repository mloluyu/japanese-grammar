# ADR-0003：静态托管与本地学习状态

- 状态：Superseded（本地学习状态部分由 ADR-0004 取代；静态托管决策继续有效）
- 日期：2026-10-09

## 背景

项目面向学习群，预算和维护时间有限，第一版不需要账户体系或跨设备同步。

## 备选方案

- 自建后端与数据库：支持账号和同步，但增加运维与安全责任。
- 静态站点 + localStorage：部署简单、无服务端个人数据。
- 第三方 BaaS：减少自建后端工作，但引入供应商、配额与配置依赖。

## 决策

第一版采用静态站点；收藏、偏好与错题记录保存在当前浏览器的 localStorage。

## 后果

无需维护后端，学习记录不会自动同步；若未来需要跨设备同步，应新增独立 ADR 评估身份验证、数据安全、成本与迁移。
