# ADR-0001：使用 VitePress 作为文档框架

- 状态：Accepted
- 日期：2026-10-09

## 背景

项目以可检索的文档为主，同时需要少量学习交互。希望降低路由、主题、Markdown 渲染和部署的维护成本。

## 备选方案

- VitePress：文档体验完善，支持 Markdown 与 Vue 组件。
- 自建 Vue + Vite SPA：灵活，但需自行处理文档渲染、路由、搜索和更多基础设施。
- Astro Starlight：同样适合文档站，但若团队更熟悉 Vue 生态，VitePress 的交互组件整合更直接。

## 决策

采用 VitePress，使用 Vue 组件实现筛选、练习和假名显示等交互。

## 后果

优点：快速建立文档站，减少重复工程。
限制：复杂应用状态不应全部塞进 Markdown；如未来产品形态变成应用优先，应重新评估架构。
