# 产品需求文档（PRD）

- 状态：Draft
- 版本：0.1
- 产品名称：日语语法知识库
- 目标平台：桌面与移动浏览器

## 1. 背景与问题

日语学习群的知识通常散落在聊天记录、个人笔记和不同网页中，难以检索、校对和持续积累。本项目通过统一的文档格式与协作流程，将语法知识整理成可长期维护的公开资源。

## 2. 目标用户

1. **查阅者**：希望按语法、JLPT 等级或主题查找知识。
2. **学习者**：希望通过例句、音频和练习巩固语法。
3. **内容贡献者**：希望通过网页编辑或 Git 提交内容。
4. **维护者/审核者**：负责内容质量、数据规范与发布。

## 3. 产品目标

- 用户能够在较少点击内找到目标语法。
- 每条语法采用统一、可校验的元数据格式。
- 用户可以完成练习并即时看到答案与解析。
- 群友不需要安装开发环境也能提出内容修改。
- 网站可通过静态托管发布，日常维护成本低。

## 4. 非目标

MVP 不实现：
- 用户注册、登录、云端同步或跨设备学习记录。
- 服务端数据库、服务端 API。
- 实时协同编辑。
- 付费课程、排行榜或复杂推荐算法。
- 自动生成并未经审核发布语法解释。
- 保证题库具备正式考试的防作弊能力。

## 5. 核心用户故事

- 作为查阅者，我可以按语法名称、例句或关键词搜索。
- 作为学习者，我可以按 JLPT 等级与标签组合筛选语法。
- 作为学习者，我可以做单选题并看到正确答案和解析。
- 作为学习者，我可以显示/隐藏例句假名并播放可用音频。
- 作为贡献者，我可以在 GitHub 网页中修改 Markdown 并发起 PR。
- 作为维护者，我可以通过自动检查发现无效元数据、重复 ID 和断开的关联。

## 6. 功能需求

### FR-01 文档阅读
- 语法正文以 Markdown 编写。
- 每条语法有稳定的唯一 ID。
- 页面显示标题、等级、标签、接续、解释、例句、相似表达和注意事项（适用时）。
- 文档缺少可选音频时仍可正常阅读。

### FR-02 搜索
- MVP 使用 VitePress 本地搜索。
- 搜索应覆盖构建索引中的标题与正文内容。
- 搜索无需向第三方服务发送查询内容。
- 搜索不是元数据筛选的替代品。

### FR-03 筛选
- 支持 JLPT 等级、标签与分类。
- 支持组合筛选与清除筛选。
- 无结果时显示明确的空状态。

### FR-04 练习
- MVP 支持单选题。
- 每题有唯一 ID、题干、选项、答案、解析。
- 练习内嵌于每篇语法条目页；不做独立练习页与跨条目抽题（M4 范围调整）。跨条目对比题通过 `grammarIds` 同时出现在相关条目上。
- 答题后展示反馈和解析，并提供相关语法链接。
- 静态站点中的题目与答案可被访问，不作为安全考试系统。

### FR-05 假名与音频
- 例句以结构化数据提供，组件以 `<ruby><rt>` 渲染假名。
- 学习组件可切换例句假名显示状态。
- 音频采用浏览器支持的格式并提供原生控制或等效控件。
- 音频不可用时不影响文本学习。

### FR-06 内容贡献
- 支持网页编辑文件并创建 PR，也支持本地 Git 工作流。
- 所有正式内容经 PR 审核后合并。
- PR 自动运行格式/数据检查和静态构建。
- 提供 Issue 模板与 PR 模板。

## 7. 非功能需求

- **可访问性**：表单控件有标签；键盘可操作；颜色不是唯一状态提示。
- **响应式**：窄屏下导航、筛选和练习仍可使用。
- **性能**：首版避免大型运行时依赖和不必要的网络请求。
- **隐私**：不收集账户或个人身份数据，不使用本地存储持久化学习数据。
- **可维护性**：内容与组件分离；元数据有自动校验。
- **可靠性**：PR 构建失败时不允许自动发布。
- **版权**：内容、图片与音频必须有合法使用依据。

## 8. MVP 验收标准

1. 公开站点可通过静态托管（Cloudflare Pages）访问。
2. 至少有 10 条示例语法，且元数据校验通过。
3. 本地搜索可找到示例标题与正文关键词。
4. 等级与标签筛选可组合使用，并支持清除。
5. 至少有一组单选题，答题后显示答案与解析。
6. 至少一个例句支持假名标注；音频可选且失败不影响页面。
7. PR 检查包含数据校验与站点构建。
8. 贡献者能按指南完成一次文档 PR。

## 9. 产品指标（初期以定性观察为主）

- 用户能否快速找到目标语法。
- 贡献者是否能在没有本地环境的情况下提交修正。
- PR 中格式与链接问题的比例是否逐步下降。
